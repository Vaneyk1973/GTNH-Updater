# Contributing

Open an issue with the OS, updater version, command, expected/actual result and a
redacted log. Never include account names, UUIDs, tokens, accounts.json, worlds or
VM credentials. Reproduce bugs on a disposable copy, not your only game save.

Keep changes focused and add a regression test for data preservation, recovery or
download behavior. Run the suite described in README.md. Building an executable
does not verify compatibility: see docs/TESTING.md and docs/RELEASING.md.

Contributions are MIT, retaining LICENSE and NOTICE. Downloaded software has its own
licenses. For security issues, use GitHub **Security → Report a vulnerability** if
enabled; do not put credentials or exploitable private details in a public issue.
